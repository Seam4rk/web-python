# Гостевая книга с модерацией

Простое веб-приложение на Flask, которое позволяет посетителям оставлять сообщения, а администратор может модерировать 
их через скрытую панель.

Введите (http://127.0.0.1:5000/admin/secret) для того чтобы перейти на страницу Администратора.

Для лучшего опыта желательно использовать приложенную базу данных.
